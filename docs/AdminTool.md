# 3. 운영툴 (Admin Tool)

## 개요

ASP.NET Core 8.0 MVC 기반의 게임 운영 관리 도구.
게임 콘텐츠 전반을 관리하고, 전투 밸런스를 직접 시뮬레이션할 수 있다.

---

## 주요 기능

**콘텐츠 관리**
- 캐릭터 / 몬스터 / 스킬 / 아이템 생성·수정·삭제
- 스테이지 구성 (챕터·웨이브·보상 설정)
- 가챠 배너 및 드롭률 설정
- 상점 아이템 및 가격 관리

**운영 도구**
- 유저 계정 조회 및 인벤토리·캐릭터 확인
- 서버 상태 모니터링 및 이벤트 이력 조회
- 몬스터 스탯 CSV 일괄 업로드

**전투 시뮬레이터**
- 파티 구성 후 실제 전투 서버 로직으로 전투 실행
- 전투 로그 페이지 단위 조회
- 밸런스 조정 후 즉시 검증 가능

---

## 기술 포인트

- 게임 서버 API를 그대로 호출하는 구조 → 운영툴과 게임 클라이언트가 동일한 서버 로직 사용
- HTTP 클라이언트 Resilience 패턴 적용 (재시도, 폴백)
- Cookie 기반 관리자 인증 (8시간 세션)
- CloudFront 기반 아이콘·초상화 에셋 미리보기
